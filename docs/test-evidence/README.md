# Test evidence

Generated by `scripts/collect-evidence.sh <org-alias>`. Each run creates a timestamped folder here.

| File | What it shows |
|---|---|
| `apex-tests.txt` | Apex test results and coverage for every RenewAI class |
| `react-tests.txt` | Vitest results |
| `react-build.txt` | Type check, lint and production build |
| `e2e-check.txt`, `e2e-timings.json` | Live story: decision, approval, audit, failure paths, with response times |
| `live-smoke.txt` | Repeatability and API checks from Days 4 to 8 |
| `decisions.txt`, `actions.txt`, `scenarios.txt` | Saved records in the org |
| `permission-sets.txt` | Which RenewAI permission sets the running user has |

Before committing, run the secret check printed at the end of the script. Keep only the latest good run in git; delete older folders.
